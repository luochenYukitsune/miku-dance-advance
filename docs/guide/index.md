# MikuDance Advance (MDA) 用户指南

## 1. 安装、目录结构与启动

### 1.1 系统要求与安装
- **下载安装包**：前往 [GitHub Releases](https://github.com/luochenYukitsune/miku-dance-advance/releases)，在对应版本的 Assets 中下载 Windows x64 安装程序。更新内容写在各版本的发布说明中，预发布版会标有 Pre-release。
- **操作系统要求**：安装器仅支持 Windows 10 及以上版本的 64 位（x64）系统。
- **可选组件**：安装过程中，“传统引擎”作为可选组件提供，可根据是否需要 MMD/MME 兼容渲染按需选择安装。

### 1.2 目录结构与卸载策略
MDA 的程序安装目录与用户个人文件目录相互分离。个人文件目录包含以下五个子目录：

| 目录名称 | 用途说明 |
|---|---|
| `Config` | 用户配置与偏好设置 |
| `Plugins` | 已导入的插件包 |
| `Recovery` | 自动保存的恢复副本 |
| `Cache` | 运行时缓存数据 |
| `Logs` | 运行日志记录 |

- **卸载保留机制**：执行卸载程序时，默认保留个人文件目录中的所有数据；仅当用户在卸载向导中明确勾选删除选项时，才会清理个人文件。

### 1.3 启动与引擎选择
启动软件时，需在**现代引擎**与**传统引擎**（若已安装）之间做出选择。当前会话的视口预览与最终渲染导出均固定使用启动时所选的同一引擎。

## 2. 资源导入、工程管理与拖拽规则

### 2.1 菜单导入与工程保存
- **导入模型**：通过“文件”菜单导入 `PMX` 或 `PMD` 模型文件。
- **导入动作与姿态**：导入 `VMD`（动作）或 `VPD`（姿态）前，必须先选中目标模型，导入的数据将作用于该选中模型。
- **打开 PMM 工程**：支持打开受支持范围内的 `PMM` 工程。若打开时检测到缺失的模型或贴图等资源，请依照提示检查并在支持时重新定位资源。
- **保存原生工程**：工程文件根据当前所处的引擎分别保存——现代引擎保存为 `.pma` 格式，传统引擎保存为 `.pmc` 格式。加载工程时软件会同时校验文件后缀与内部身份标识。

### 2.2 拖拽导入规则
支持直接将本地文件拖入软件窗口，具体规则如下：

| 规则维度 | 详细说明 |
|---|---|
| **支持格式** | `PMA`、`PMC`、`PMM`、`PMX`、`PMD`、`VMD`、`VPD` |
| **单次数量限制** | 单次最多可同时拖入 `1–32` 个本地文件 |
| **工程文件互斥** | `PMA`、`PMC`、`PMM` 工程文件必须单独拖入打开，不可与其他文件混合拖入 |
| **混合素材顺序** | 同时拖入多个模型与动作/姿态素材时，系统按**先加载模型、后加载动作/姿态**的顺序执行，且动作/姿态作用于当前选中的模型 |
| **中断处理** | 批量拖入处理过程中，若任一环节被用户取消或加载失败，后续未处理的文件将立即停止加载 |

## 3. 时间轴关键帧编辑

### 3.1 范围选择与过滤
- **选择范围**：时间轴的范围选择采用**闭区间**（包含起始帧与结束帧）。
- **作用对象**：范围选择仅选中**当前模型**在区间内已有的**骨骼**、**表情**和 **IK** 关键帧；不会包含其他模型、相机或灯光的关键帧。
- **清空选择**：执行取消选择操作即可清空当前已选中的关键帧集合。

### 3.2 编辑操作与撤销
- **复制与粘贴**：粘贴关键帧时，以**当前时间轴所在帧**对齐已复制集合中的**最早选中帧**，并保持各关键帧之间的相对帧间距不变。若目标位置已存在关键帧产生冲突，系统会先弹出确认提示。
- **移动与删除**：对已选关键帧执行移动或删除操作时，作用范围**包括当前处于隐藏状态的已选关键帧**。
- **历史记录**：关键帧的编辑操作均支持撤销（Undo）与重做（Redo）。

## 4. 自动保存与异常恢复

- **默认策略**：自动保存功能默认开启，每 `3 分钟` 执行一次，每个会话最多保留 `5 份` 副本，默认总容量上限为 `5 GiB`。
- **独立存储**：自动恢复副本默认存储在个人文件目录的 `Recovery` 中，也可在设置中修改位置，完全独立于用户手动保存的工程文件。
- **恢复触发机制**：
  - 当软件发生异常中断后再次启动时，用户可选择从自动保存副本中恢复工程。
  - 若软件为正常关闭，下次启动时不会反复提示历史遗留的异常副本。
- **目录变更说明**：若在设置中更改了自动恢复目录的路径，系统不会自动迁移旧目录中的既有副本。

## 5. 视口预览与渲染导出

### 5.1 预览画质与低帧率提示
- **画质独立**：视口预览画质与导出画质相互独立设置，互不影响。
- **FPS 监测**：状态栏实时显示视口实际呈现帧率（FPS）。当 FPS 持续低于 `24` 达到 `5 秒` 时，软件会弹出提示建议调整预览画质，但**不会自动修改**当前的画质设置。

### 5.2 导出格式与音轨规则
- **图像导出**：支持导出 `PNG` 单张图片或 `PNG` 图像序列，均可包含透明通道（Alpha）。
- **视频与音频导出**：
  - 视频编码导出使用 `FFmpeg`。
  - 支持在导出视频时附带一条处于**启用状态**的 `PCM WAV` 音轨。
  - 若工程中存在多个启用的音轨，将被拒绝，不会自动混音。

### 5.3 时间轴帧率换算与边界规则
- **源时间轴基准**：MDA 源时间轴固定为 `30 fps`。
- **区间边界计算**：导出范围采用**起始帧包含、结束边界不含**的规则。例如：设置导出范围为 `0` 到 `300` 时，实际时长为 `10 秒`；若选择以 `60 fps` 帧率导出该区间，最终将输出 `600 帧`。

### 5.4 显存模式设置
- **现代引擎**：导出时提供三种显存管理模式——**自动**（默认）、**优先速度**、**低显存**。
- **传统引擎**：导出时不开放手动显存模式选项。

## 6. 插件管理

- **导入与启用**：通过菜单栏“帮助 → 插件”选择本地 `.zip` 插件包进行导入，导入完成后需在插件列表中手动启用。
- **命令显示**：界面中仅显示当前所选插件已注册的扩展命令。
- **安全警告**：插件与主程序在**同一进程、以相同系统权限**直接运行，**并非安全沙箱**。请仅导入和启用来源可信的插件。

## 7. 常见问题解答 (FAQ)

| 问题现象 | 原因与解决方法 |
|---|---|
| **启动或使用时提示缺少传统组件** | 安装软件时未勾选可选的“传统引擎”组件。如需使用传统引擎或打开 `PMC` 工程，请通过安装程序补充安装传统引擎组件。 |
| **在现代引擎中加载 MME / FX / EMM 无效果** | 现代引擎基于 D3D12 架构，设计上不执行任何 MME、FX 或 EMM 特效数据。如需使用受支持范围内的 MME 特效，请在启动时切换至传统引擎。 |
| **预览时弹出低帧率（低于 24 FPS）提示** | 当视口实际呈现帧率持续 5 秒低于 24 FPS 时会触发该提示。软件不会自动降级画质，您可手动前往预览设置降低预览画质以提升流畅度（不影响最终导出画质）。 |
| **打开 PMM 或工程时提示资源缺失** | 工程引用的模型、贴图或音频路径发生变动。请根据提示检查资源路径，并在支持时重新定位。 |
