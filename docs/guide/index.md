# MikuDance Advance 用户指南

## 1. 安装、目录与文件关联

前往 [GitHub Releases](https://github.com/luochenYukitsune/miku-dance-advance/releases) 下载对应版本的 `MDA-<版本>-win-x64-setup.exe` 安装程序（标有 `Pre-release` 的版本为预发布版）。安装程序支持 Windows 10 及以上 64 位（x64）系统，内置 FFmpeg 的上游系统基线为 Windows 10 22H2；安装向导界面提供简体中文、英文与日文。

安装时默认包含编辑器、内置 FFmpeg／ffprobe 以及现代渲染引擎（含 Direct3D 12 着色器编译器、FSR／XeSS／DLSS 超分辨率运行库以及默认启用的四套官方画风插件：`原神`、`星穹铁道`、`鸣潮`、`终末地`）。需要使用原版 MMD／MME 特效时，可在向导中一并勾选可选的“传统 MMD / MME 渲染引擎”并确认 DirectX 运行库许可。

MDA 的程序安装目录与个人文件目录分开存放。个人文件目录可在安装向导中指定或沿用默认位置，内部包含五个子目录：

| 子目录 | 保存内容 |
|---|---|
| `Config` | 界面外观、语言、外部工具路径与偏好设置 |
| `Plugins` | 用户导入的插件包及插件启用状态配置（`enabled.json`）；程序安装目录 `plugins/` 另行存放随附的官方画风插件 |
| `Recovery` | 自动保存的恢复副本 |
| `Cache` | 运行时缓存 |
| `Logs` | 运行与诊断日志 |

卸载软件时默认保留个人文件目录中的全部内容，只有在卸载向导中明确选择“删除个人文件”时才会清理；你自己的工程、模型素材和导出的视频始终留在原位置。

向导支持注册 Windows 文件关联：默认勾选 `.pma`（现代工程）与 `.pmc`（传统工程），也可按需勾选 `.pmm`、`.pmx`／`.pmd`、`.vmd`、`.vpd`。双击已关联的文件（或通过命令行 `Mmd.Modern.App.exe --open "文件路径"` 启动）即可直接打开工程或导入素材；尚未设置默认应用的后缀会自动关联，已被其他程序占用的后缀可在安装后到 Windows“默认应用”中切换。

## 2. 双渲染引擎、画风灯光与传统特效

每次启动 MDA 时需选择本次会话使用的渲染引擎，视口实时预览与最终渲染导出共用同一个引擎。现代工程保存为 `.pma`，传统工程保存为 `.pmc`，打开工程时程序会同时核对文件扩展名与包内格式标识，不跨引擎混用。

### 2.1 现代引擎（Direct3D 12）

现代引擎默认内置并保持 `MMD 原版` 配色与三渲二观感（不运行 MME `.fx`／`.emm` 特效），同时通过插件化管线提供可停用或扩展的画风、多光源工作台、超分辨率与全局光照：

- **画风与材质**：引擎内置 `MMD 原版` 基线画风，并随程序附带且默认启用 `原神`、`星穹铁道`、`鸣潮`、`终末地` 四套官方画风插件（可在“帮助 → 插件”中按需停用或重新启用，也支持导入第三方画风插件）。右侧“画风”页可切换当前已启用的工程画风；在“模型 → 模型属性…”／“材质与画风…”或右侧“材质”页中，面板会根据所选画风插件声明的模式定义动态生成对应的材质模式、参数控件、贴图槽位、骨骼追踪选项、多语言校验提示以及逐材质轮廓描边粗细倍率。若打开的 `.pma` 工程引用了已停用或未安装的画风插件，原绑定数据会被完整保留并安全回退至 `MMD 原版` 基线渲染，界面提供“一键启用本地对应插件”或可撤销的批量画风替换向导。
- **主光与附加灯**：除调节主光源方向、方位角／仰角和快捷朝向外，可在左侧“灯光”页或视口上方工具栏添加方向光、点光、聚光和面光源（柔光箱），支持按组管理、关键词搜索、应用内置布光预设或导入／导出 JSON 灯光预设，并可统一调节环境光与整体曝光、一键开关视口“灯光辅助”线框。单个工程最多保存 `128` 盏附加灯、同时启用 `32` 盏。
- **超分与全局光照**：在“视图 → 预览画质”中可配置抗锯齿（SMAA、精细采样 SSAA）、空间超分（FSR 1）与时域超分（FSR、XeSS、DLSS），以及软件或硬件光线追踪全局光照（GI）。硬件光追与厂商超分是否可启用由当前显卡与驱动在运行时检测（硬件光追需显卡支持 DXR 1.1 与 Shader Model 6.5）。

### 2.2 传统引擎（Classic）

选择传统引擎进入主界面后，顶部菜单栏会显示 `MMEffect` 菜单，用于原版 MMD 渲染与 MME 特效配置：

- **特效分配与离屏页**：打开“MMEffect → 特效分配…”可按对象或材质子集指定 `.fx` 特效。新指定带有离屏渲染目标的 `.fx` 时，程序会自动生成对应的命名分配页；替换或移除特效时，若旧分配页中已有分配内容，会先弹窗确认是否连同内容删除（删除操作可撤销）。菜单中还提供 `Ctrl+Shift+E` 总开关、手动／文件变化自动重新载入特效、保存 `.emm` 分配文件及查看特效日志。
- **Toon 贴图与十槽管理**：可通过“Toon 贴图设置…”按材质替换 Toon 图片，或在“Toon 01–10 槽位…”中按模型集中查看和替换原版十个共享 Toon 槽（共用同一槽位的材质会同步更新，不改动模型原文件里的 Toon 编号；已配置本机原版 MMD 目录时支持一键恢复默认）。
- **独立工程打包**：保存 `.pmc` 工程时会将模型、贴图、动作、音频以及引用的 `.fx`、include 头文件、`.emm` 和自定义 Toon 贴图一并打入包内，方便跨目录或跨机器打开。

## 3. 素材导入、工程保存与拖拽

通过“文件”菜单可新建或打开工程，导入模型（`.pmx`、`.pmd`）、动作（`.vmd`）与姿态（`.vpd`），保存 `.pma`／`.pmc` 工程或另存为原版 `.pmm` 工程，也可将当前动作或姿态导出为文件。导入 `.vmd` 或 `.vpd` 前需先在列表中选中目标模型；若要更换已导入角色的模型文件，可使用属性面板中的“更换…”，程序会按骨骼与表情名称保留已有动作和外亲设置。打开 `.pmm` 或工程时若遇到缺失的模型、贴图或音频，可按弹窗提示重新指定文件路径。

主窗口支持直接从资源管理器拖入 `1–32` 个本地文件（支持 `.pma`、`.pmc`、`.pmm`、`.pmx`、`.pmd`、`.vmd`、`.vpd`）：

- `.pma`、`.pmc`、`.pmm` 工程文件需单独拖入打开，不能与其他文件一起混拖；
- 同时拖入多个模型与动作／姿态文件时，程序会先依次加载模型，再将动作或姿态应用到当前选中的模型；
- 批量拖入过程中若手动取消或某个文件加载报错，后续尚未处理的文件会立即停止加载。

## 4. 时间轴与关键帧编辑

时间轴左上角提供两种轨道视图：`全部轨道` 按分组展开当前模型的所有骨骼、表情与 IK 轨道；`跟随所选` 仅显示当前选中的那一根骨骼或表情轨道，方便专注修单条通道。

- **选中关键帧**：可在轨道上点击菱形单选、按住 `Ctrl` 点击多选，或在时间轴上方填写“起始帧”与“结束帧”后点击“按范围选择”。范围选择采用闭区间（含首尾两帧），只选中当前模型在该区间内已有的骨骼、表情和 IK 关键帧，不会把其他模型、相机或主光的关键帧混入其中。
- **复制、粘贴、移动与删除**：粘贴关键帧时，以当前帧对齐复制集合中最早的那一帧，其余关键帧保持原有的帧间距；目标位置已有关键帧时会先弹窗确认是否覆盖。
- **隐藏轨道保护**：在选中关键帧后若切换到 `跟随所选`，不在当前可见轨道上的已选关键帧会保留选中状态并在工具栏提示隐藏数量；为避免误删或误移看不见的轨道，此时移动、删除以及带隐藏骨骼关键帧的插值曲线编辑会暂时禁用，切回 `全部轨道` 或点击“取消选择”即可继续操作。

常用操作快捷键如下：

| 快捷键 | 作用 |
|---|---|
| `Space` | 播放／暂停（焦点不在文本输入框内时） |
| `Enter` / `K` | 为当前选中的通道添加关键帧 |
| `Ctrl+C` / `Ctrl+V` / `Delete` | 复制、粘贴、删除所选关键帧 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销／重做 |
| `←` / `→`（时间轴聚焦） | 前后移动 1 帧；按住 `Shift` 每次跳 10 帧 |
| 鼠标滚轮 / `Ctrl + 滚轮`（时间轴） | 左右平移时间轴／缩放时间轴刻度 |
| 数值滑块双击 / 滚轮 | 双击恢复默认值；点选后滚轮微调（按住 `Shift` 更细，`Esc` 撤回本次拖动） |

## 5. 自动保存与异常恢复

自动保存默认开启，每 `3 分钟` 将当前编辑进度写入一份独立的恢复副本（未命名的新工程同样包含在内），单次会话最多保留 `5 份`，恢复目录默认总空间上限为 `5 GiB`。所有参数和存放文件夹均可在右上角“设置 → 自动保存”中调整（间隔 `1–60` 分钟，份数 `1–20` 份）；修改存放文件夹只对之后新生成的副本生效，旧文件夹里的既有副本不会自动搬移。

恢复副本与手动保存的原工程完全分开，不会覆盖你的 `.pma` 或 `.pmc` 文件。软件因崩溃或断电异常退出后，下次启动时会列出可恢复的版本供选择；正常关闭软件后，下次启动不会弹出旧副本提示。

## 6. 预览监测与渲染导出

### 6.1 预览帧率与画质调节

视口预览画质与最终导出画质各自独立保存。底部状态栏实时显示按实际完成呈现的画面计算的预览 FPS；当预览帧率连续 `5 秒` 低于 `24 fps` 时，右上角会弹出卡顿提醒并提供前往“预览画质”的快捷入口，程序本身不会擅自改动你的画质设置。显存紧张时，现代引擎会自动临时下调当前预览的精细采样倍率以维持视口运行，已保存的设置和导出参数不受影响。

### 6.2 图片与视频导出

通过“输出 → 导出图片… / 导出视频…”或右上角“导出”按钮打开输出配置窗口：

- **图像与透明通道**：支持导出单张 `PNG` 或 `PNG` 图像序列，勾选“透明背景（PNG）”可输出带 Alpha 通道的透明底图；同时开启柔光时可限定仅作用于轮廓内部，避免半透明边缘发灰或溢色。
- **视频编码**：安装包自带 FFmpeg 与 ffprobe，支持软件编码（H.264 `libx264`、HEVC `libx265`、AV1 `libaom-av1`／`libsvtav1`）、NVIDIA NVENC 硬件编码（H.264、HEVC、AV1）以及无压缩 `rawvideo`，可配置恒定画质或目标码率、编码速度、关键帧间隔与软件编码线程数。
- **音轨要求**：导出视频时可附带一条处于启用状态的 `PCM WAV` 音频文件作为输入音源；若工程中同时启用了多条音轨，导出会直接提示拒绝，不会自动混音。
- **时间轴与物理预热**：源时间轴固定为 `30 fps`，导出帧范围按左闭右开 `[起始帧, 结束帧)` 计算（例如 `0` 到 `300` 帧为 `10 秒`，按 `60 fps` 导出则输出 `600 帧`）。高级选项中可设置“物理预热帧数”，在起始帧之前先推算刚柔体物理让衣物与头发自然垂落，预热帧不会写入输出文件。
- **显存模式与状态监控**：现代引擎在导出时提供 `自动`（默认）、`优先速度`、`低显存` 三种显存模式。“渲染状态”窗口会实时展示帧进度及本进程的 CPU、内存、GPU 与显存峰值，报错时可直接复制诊断日志。

## 7. 插件与常见问题

点击“帮助 → 插件”可打开插件管理窗口，统一管理随附的官方画风插件与用户导入的 `.zip` 插件包（支持 `editor.commands` 编辑器命令与 `rendering.styles` 现代 D3D12 渲染风格两类 API 1 扩展）。选择本地 `.zip` 插件包或直接将 `.zip` 拖入窗口即可导入：随附官方画风插件默认启用，用户导入的新插件默认停用并在手动启用后生效；列表会区分来源并展示能力徽章、插件说明、提供的画风列表及可折叠目录详情，停用当前工程正在使用的画风插件时还会给出警告提示，右侧可执行插件注册的编辑器命令。插件与 MDA 主程序在同一进程、以相同系统权限运行，没有安全沙箱隔离，请只导入和启用来源可信的插件。编写插件请参考[插件 API 1 开发规范](../development/plugins.md)。

| 常见情况 | 原因与处理办法 |
|---|---|
| 打开 `.pmc` 或启动时提示缺少传统引擎／引擎不匹配 | 安装时未勾选“传统 MMD / MME 渲染引擎”，或当前会话选成了现代引擎。运行安装程序补装传统引擎，并在启动时选择对应引擎重新打开。 |
| 在现代引擎里导入含 MME 的工程后特效不生效 | 现代引擎基于 Direct3D 12，不执行 `.fx`／`.emm` 特效（从 `.pmm` 识别到的 MME 记录仅随工程保留）。需要使用 MME 特效请在启动时选择传统引擎。 |
| 传统引擎“Toon 01–10 槽位”中“恢复默认”不可点 | 尚未指定本机原版 MMD 目录（程序本身不打包原版 MMD Toon 贴图）。选择原版 MMD 文件夹后即可恢复默认，直接替换自定义 Toon 图片不受影响。 |
| 时间轴选中关键帧后无法移动或删除 | 当前处于 `跟随所选` 视图，部分已选关键帧位于未显示的轨道上。切回 `全部轨道` 确认选中范围，或点“取消选择”后再操作。 |
| 打开 `.pma` 工程时提示画风不可用，或停用画风插件后画面退回 `MMD 原版` | 对应画风插件当前处于停用状态或尚未安装，工程中保存的画风与材质绑定数据不会丢失。可在替换向导中一键启用已发现的本地插件，或构造可撤销的批量替换方案切换至其他可用画风；若为第三方画风插件，在“帮助 → 插件”导入其 `.zip` 包并手动启用后即可恢复原效果。 |
