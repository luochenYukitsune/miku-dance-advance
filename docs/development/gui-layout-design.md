# GUI 设计访谈与决定

2026-11-24 更新。本文记录主界面改版的设计决定，供实现和验收使用。2026-11-23 的访谈交接确定了布局；后续问答细化了 K 帧操作，并调整了材质编辑的优先级。文中的“已确认”指用户选定的设计，“待确认”指仍需决定的细节。

## 主界面如何分区

| 已确认的问题 | 设计决定 |
| --- | --- |
| 哪种工作最需要主界面的空间？ | 优先服务 K 帧，包括摆关键姿势、编辑动作和调整节奏。当前先细化选骨、转轴、镜像复制和注册。 |
| 时间轴放在哪里？ | 左侧全高，宽度可拖动，默认约 300～340 px。跟随模型、镜头或灯光切换对应轨道。顶部保留紧凑帧工具和「全部 / 仅看有帧」筛选。 |
| 视口下方放什么？ | 中央视口下常驻一行播放和帧控制。展开后约 150～170 px，分为插值曲线、表情、骨骼或镜头数值与注册三列。选镜头时收起表情列，窄屏用标签切换。底区可一键折叠到播放行。 |
| 如何调整表情？ | 按原版 MMD 的眉、目、口、其他四组并排操作。每组有下拉选择、滑条和注册，并提供「当前非零表情」视图，方便修已有 VMD。 |
| 对象和属性放在哪里？ | 右上统一大纲列出模型、镜头和灯光，可按「全部 / 模型 / 灯光」筛选，可拖动分隔线或折叠。右下放属性。原右侧「动画」页的职责移入时间轴与视口底区。 |
| 预览画质从哪里打开？ | 保留独立弹窗。菜单、视口顶栏和底部状态栏的帧率处都可以打开，调 GI、抗锯齿或超分时能保留当前属性页。 |

## K 帧问答

| 问题 | 已确认的操作与结果 |
| --- | --- |
| 第 20 帧依次调了肩、肘和手腕，最后选中手腕，按一次 `Enter` 注册哪些骨骼？ | 把当前角色在该帧手动改过的肩、肘和手腕一起注册到第 20 帧。最后选中的骨骼不限制注册范围。 |
| 两名角色在第 20 帧握手，A 的右腕和 B 的左腕都有草稿。选中 B 时按 `Enter` 呢？ | 只注册当前角色 B 在第 20 帧改过的骨骼。A 的草稿保留，切回 A 后可继续调或注册。 |
| 当前角色在当前帧没有骨骼草稿，想给脚 IK 补一枚保持姿势的键，按 `Enter` 会怎样？ | 按当前姿势给此刻选中的骨骼打帧。只选脚 IK 就只给脚 IK 打帧；多选则给每根选中的骨骼各打一枚。其他角色或其他帧的草稿不影响这个判断。 |
| 还没注册就跳到第 24 帧怎么办？ | 第 20 帧保留姿势草稿，时间轴给出明显标记。返回第 20 帧时恢复草稿，用户继续微调或手动注册。 |
| 有未注册的姿势草稿时，按 `Ctrl+S` 保存工程会怎样？ | PMA 和 PMC 工程都随正式关键帧一起保存草稿，重开工程后仍可在对应帧继续编辑。草稿在保存、关闭、重开后仍是草稿，按 `Enter` 注册才成为正式关键帧。 |
| 第 10、30 帧有正式键，第 20 帧有草稿，播放时看到什么？ | 播放按正式键计算动作和插值。停回第 20 帧编辑时显示草稿，并明显提示还有改动待注册。标记的图形、颜色和具体文案待定。 |
| 左栏默认列出哪些骨骼？ | 遵循原版 MMD 的表示枠，沿用模型作者定义的组名、顺序和成员。展开一个组即可查看其中的轨道。 |
| 导入的 VMD 给分组外的骨骼打了帧，怎样找回这条轨道？ | 在时间轴末尾增加默认折叠的「未分组・已有帧」。打开后能找到这些骨骼的键；没有键的未分组辅助骨骼不占行。 |
| 摆好了右臂，怎样给左臂同样的姿势？ | 沿用原版两步操作。选中右肩、肘和手腕，点「复制姿势」，再点「反转粘贴」。左臂的姿势可继续微调，最后按 `Enter` 注册。 |
| 选中肘或手腕后，从哪里拖动旋转轴？ | 两种入口都保留。平时直接拖骨骼旁的三色旋转环；骨骼被遮挡或在画面里太小时，拖视口角落固定的 X / Y / Z 轴控件来旋转同一根骨骼。 |

**视口选骨与时间轴联动（已确认）。** 在视口选中骨骼时，左侧时间轴保留各表示枠的展开状态和当前滚动位置，并高亮该骨骼所属的组。例如查看腿部关键帧时点选手腕，「腕」组保持收起；点击组名才展开查看手腕轨道。

**视口重叠选骨（已确认）。** 沿用原版 MMD 的两种入口。多个骨骼标记重叠时，在视口同一点重复左击，切换当前选中的骨骼；也可以展开左侧表示枠，直接点击骨骼名称选中。[重叠骨骼的原版操作说明](https://w.atwiki.jp/vpvpwiki/pages/331.html) · [从表示枠选择骨骼的示例](https://mikumikud.hatenablog.com/entry/2011/10/12/141042)

**折叠组的菱形仍待确认。** 用户要求参照原版。原版教程显示，折叠行的灰菱形汇总子行该帧的键，已选中的红色键可以一起左拖。点组名可以选择骨骼。对于直接按下折叠骨骼组的灰菱形，MMD 9.32 在此次操作中选中的子键范围仍待实测。MDA 的讨论方案是按下「左臂」组第 20 帧的菱形即高亮当帧肩、肘两枚键，拖到第 24 帧时仅移动这两枚键，手腕的第 22 帧保留。此方案还未拍板。[原版分组菱形图解](https://learnmmd.com/StartHere/Steps2.html) · [已选关键帧移动演示](https://mikumikud.hatenablog.com/entry/2011/10/20/161800) · [原版姿势复制与反转粘贴](https://mikumikud.hatenablog.com/entry/2011/10/13/001553)

## 画风、材质和灯光

| 问题 | 已确认的方向 |
| --- | --- |
| 如何给角色定画风？需要经常手调 PMX 颜色吗？ | 各种画风作为预设插件。支持工程默认画风和模型覆盖。角色手工调色是低频工作，日常 K 帧流程只需选预设、看效果。 |
| 需要把视口材质吸管放在主界面吗？ | 用户强调动画软件优先 K 帧。吸管和逐项调 PMX 颜色已移出本轮主界面方案。交接中原列为现代「画风 / 材质 / 灯光」三页；精简后「材质」页保留哪些低频操作仍待确认。已有插件、材质绑定和工程数据继续保留。 |
| 现代工程如何组织灯光？ | 平行光、点光、聚光和面光都是大纲里的对象。由一盏普通平行光承载 PMM/VMD 的灯光轨。原独立「场景灯光」窗口的操作并入主界面。 |
| 选灯时如何与右栏联动？ | 大纲选灯会打开「灯光」页。在该页点回模型查看位置或骨骼，可以继续保留灯光上下文。编辑画风时仍可在视口拖灯；视口顶栏提供灯光辅助体显隐及灯光开关。 |
| 灯光页首屏显示什么？ | 顶部为名称、灯型、开关。首屏显示颜色、亮度、阴影开关与当前灯型最重要的 1～2 项形状参数。位置朝向、父骨骼和照射对象收进两个紧凑折叠区。调向以视口直拖为主，辅助对准放进小菜单，移除大方向圆盘和三行对准按钮。 |
| 灯光预设从哪里操作？ | 「添加三点光、导入灯组」放在右上大纲的灯光菜单。「保存当前灯为预设、将预设套用到当前灯」放在右下灯光页。 |
| Classic 工程显示哪些控制？ | 保留可调的初始场景光和独立 MME / Toon 工作流，隐藏现代专属画风和材质页。 |

交接中提出的按住对比 MMD 原配色、按角色或「仅看已修改」筛材质、材质列表与视口高亮联动，后续结合预设优先的方向复核。用户已确认的低频模型属性包括模型变换、IK / 物理开关和 JSON 映射导入导出。灯光页的环境与曝光排布、重置手势、灯光帧注册入口，以及两条工具栏去重、大纲的批量操作、Classic 模式 MME 的附加快捷入口，均待定。

## 改版必须保留的一键替换模型与外亲

用户要求在新布局中继续提供现有的「一键替换模型」，同时保留外亲关系。验收时分别覆盖被替换模型作为外亲父端和子端的工程。

- 成功映射时保留模型实例身份、外亲双方的对象身份和绑定偏移；被替换一端按唯一同名骨骼重新映射。
- 骨骼缺失、重名或恢复后会产生冲突、循环时，沿用已有流程，暂停绑定并保存记录，供用户显式恢复。取消替换应完整保留当前工程状态。
- 现有替换操作可从模型浏览器、模型右键菜单和当前模型检查器进入。布局调整时需保留容易找到的入口，以及替换后的选择和属性刷新。[编辑器替换流程](../../src/Mmd.Modern.App/EditorWindow.ModelReplacement.cs) · [外亲与替换回归](../../tests/Mmd.Modern.Application.Tests/SceneModelReplacementTests.cs) · [界面替换回归](../../tests/Mmd.Modern.Tests/WorkbenchReplacementUiTests.cs)

## 本分支的验收操作

1. 打开带表示枠的角色，在左栏展开腿部，再到视口点选手腕。腿部列表保持原来的滚动位置，手腕所属组高亮。在重叠骨标上连续左击可以轮换选骨。按 `E` 进入旋转模式，骨骼旁的旋转环和视口角落的 X / Y / Z 控件操作同一根骨骼。
2. 在第 20 帧依次调肩、肘、腕，然后跳到别的帧，再保存并重开工程。回到第 20 帧应能继续调整三根骨骼。播放时检查正式动作，停止后按 `Enter` 一次注册三根骨骼。对于已有草稿的另一角色，切回去后仍可单独注册。当前帧没有骨骼草稿时，可多选几根骨骼按 `Enter` 补保持键。
3. 选中右臂各骨，依次点「复制姿势」「反转粘贴」。在左臂微调后注册。打开视口下方的动画工具检查表情四组、当前非零表情和插值曲线，再把底区收回到播放行。
4. 在右上大纲选择镜头或「平行光 · VMD」，在左栏查看对应的正式关键帧。现代工程可从大纲灯光菜单添加三点光、室内窗光或导入灯组。选中某盏附加灯，可在右下套用单灯预设，其对象身份、摆放、外亲和照射对象保留。切回画风页后仍可用视口调整灯光。VMD 平行光的方向与颜色沿用工程原有灯光轨和注册流程。
5. 在画风页设置工程默认预设，再选择一个角色覆盖预设，检查其他继承默认画风的角色。在窄窗口检查工程默认画风和模型画风是否同时可见。展开「材质设置」切换材质用途推断，或打开缺失画风的替换窗口。取消或完成替换后，当前骨骼的姿势草稿仍可继续编辑。用大纲的一键替换入口分别替换外亲的父端、子端，核对绑定恢复与未匹配骨骼提示。Classic 工程从右栏进入 MME 工作流。
6. 将窗口缩到 1100 × 720，在视口底部依次切到「表情」和「数值与注册」。检查表情四组的注册键、当前骨骼的位置与旋转、复制姿势、反转粘贴和注册均能直接操作。切到镜头后可看到当前投影方式并修改相机参数。
