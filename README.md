# MikuDance Advance (MDA)

MikuDance Advance（简称 MDA）是一款运行在 Windows x64 桌面端的 MMD 工程编辑与渲染软件。软件支持导入常见的 MMD 资源与工程，提供时间轴关键帧编辑、实时视口预览以及图片与视频导出功能。

- **开源仓库**：<https://github.com/luochenYukitsune/miku-dance-advance>（源码已公开）
- **安装包下载**：待发布

---

## 主要功能

### 资源导入与工程管理

| 功能类别 | 具体说明 |
|---|---|
| **资源导入** | 支持导入 `PMX` / `PMD` 模型、`VMD` 动作数据、`VPD` 姿态数据，以及有范围支持的 `PMM` 工程文件。 |
| **原生工程格式** | 现代引擎使用 `.pma` 格式，传统引擎使用 `.pmc` 格式。加载工程时会同时校验文件后缀与内部身份标识。 |
| **自动恢复** | 提供独立于手动保存的自动恢复副本机制，降低意外退出导致的数据丢失风险。 |

### 时间轴编辑

支持对当前选中模型的**骨骼**、**表情**、**IK** 关键帧进行以下操作：
- 关键帧范围选择
- 复制与粘贴
- 移动与删除
- 撤销与重做

### 预览与渲染导出

| 功能类别 | 具体说明 |
|---|---|
| **画质独立配置** | 视口预览画质与最终导出画质分别独立设置。 |
| **帧率监测与提示** | 状态栏实时显示视口实际呈现 FPS。当帧率持续 5 秒低于 24 FPS 时，软件会提示调整预览画质（不会自动降低或修改用户的画质设置）。 |
| **图像导出** | 支持导出 `PNG` 单张图片、`PNG` 图像序列。 |
| **视频与音轨导出** | 支持导出视频文件，并可附带一条处于启用状态的 `PCM WAV` 音轨。 |

### 插件扩展

- **导入与启用**：支持通过菜单栏“帮助 → 插件”导入 `.zip` 插件包，导入后需由用户手动启用。
- **插件能力（API 1）**：当前版本 API 1 提供命令扩展支持。
- **运行机制**：插件直接在宿主进程内运行，**不包含安全沙箱隔离**，请仅导入和启用来源可信的插件。

## 两种渲染引擎

MDA 在启动时供用户选择**现代引擎**或**传统引擎**。选定后，当前会话的视口预览与最终渲染导出均使用同一引擎。

| 对比维度 | 现代引擎 | 传统引擎 |
|---|---|---|
| **图形接口 / 特性** | 基于 Direct3D 12 (D3D12) | 提供有明确范围的 MMD / MME 兼容支持 |
| **原生工程文件** | `PMA` | `PMC` |
| **特效与兼容性** | 不执行 MME、FX 及 EMM 数据 | 支持特定范围内的特效兼容，但不保证支持任意特效，也不承诺与原版 MMD 逐像素一致 |
| **安装方式** | 核心默认安装 | 安装时可作为可选组件按需勾选 |

## 系统要求与快速入门

### 系统要求

- **操作系统**：Windows 10 及以上版本（64 位 / x64）
- **其他硬件配置**：待发布

### 快速入门

1. **安装软件**：获取官方安装程序（待发布），按向导完成安装。如需使用传统兼容模式，请在安装时勾选“传统引擎”组件。
2. **选择引擎**：启动 MDA，根据工程需求选择进入“现代引擎”或“传统引擎”。
3. **导入与编辑**：导入 `PMX`/`PMD` 模型及 `VMD`/`VPD` 动作姿态（或导入受支持的 `PMM` 工程），在时间轴中编辑骨骼、表情和 IK 关键帧。
4. **保存工程**：将工程保存为对应引擎的原生格式（现代引擎为 `.pma`，传统引擎为 `.pmc`）。
5. **渲染导出**：配置导出画质参数，选择导出为 PNG 单图、PNG 序列或带 PCM WAV 音轨的视频。

## 架构模块与文档

### 产品模块组成

MDA 由六个核心产品模块构成：
1. **MMD 核心**：处理模型、动作、姿态与基础数据逻辑。
2. **现代引擎**：基于 D3D12 的渲染与管线模块。
3. **传统引擎**：面向 MMD/MME 兼容范围的渲染模块。
4. **GUI**：桌面端图形用户界面与交互框架。
5. **视图**：视口呈现、帧率统计与画质控制。
6. **插件加载器**：管理插件包导入、生命周期与 API 1 命令扩展。

## 已知限制与版本说明

- **工程与引擎绑定**：现代工程（`PMA`）与传统工程（`PMC`）各自具有内部身份校验，预览与导出均固定使用当前启动所选的引擎。
- **兼容性边界**：
  - 现代 D3D12 引擎完全不执行 MME、FX 和 EMM。
  - 传统引擎仅在明确定义的范围内提供 MMD/MME 兼容，不保证支持任意第三方特效，也不保证画面与传统软件逐像素一致。
  - `PMM` 工程导入为有范围支持，并非全部特性无损还原。
- **音轨格式限制**：视频导出目前仅支持合成一条已启用的 `PCM WAV` 音轨。
- **插件安全性**：插件运行在主进程中，无沙箱隔离机制。
